# Chrome Web Store Listing Copy

## Name

Usage Pacer

## Short description

Pace your Cursor usage against the billing-cycle reset date.

## Full description

Usage Pacer helps Cursor users pace their included usage through each billing cycle. It reads the reset date and usage summary from cursor.com, then shows elapsed time versus usage, pace delta, days left, and a depletion forecast in the toolbar and popup.

Data stays on-device; there is no backend or analytics. The extension uses your existing cursor.com session only to request Cursor's own usage summary.

## Category

Developer Tools

## Language

English

## Privacy policy note

The Chrome Web Store requires a publicly accessible privacy policy URL because the extension checks the existing cursor.com session. Host `privacy-policy.md` at a public URL before submitting the item for review.
